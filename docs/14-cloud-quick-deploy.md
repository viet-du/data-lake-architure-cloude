# 🚀 Quick Cloud Deployment Guide (3 lựa chọn)

## So sánh nhanh

| Cloud | Setup | Cost | Phù hợp cho |
|-------|-------|------|-------------|
| **Oracle Cloud** ⭐ | 🟡 Trung bình | **$0 vĩnh viễn** | Sinh viên, dự án 24/7 |
| **GCP** | 🟢 Dễ | $0.5-5/tháng | Project chuyên nghiệp |
| **AWS** | 🟡 Trung bình | $1-10/tháng | Doanh nghiệp |

## 🎯 Khuyến nghị cho bạn

### Sinh viên / Đồ án → **Oracle Cloud**
- 4 ARM VM 24GB RAM **VĨNH VIỄN**
- Đủ chạy toàn bộ stack (MinIO + Kafka + Spark + Airflow)
- Setup 1 lần, chạy 24/7

### Dùng thử / POC → **GCP Free Tier**
- $300 credit trong 90 ngày
- BigQuery free 1TB query
- Quản lý dễ, UI đẹp

### Production / Doanh nghiệp → **AWS / GCP paid**
- Hỗ trợ tốt, nhiều region
- Tính ổn định cao
