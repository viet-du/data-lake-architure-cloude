# Background Images

Thư mục chứa background patterns / textures / hero backgrounds dùng cho app shell, splash screen, glassmorphism overlay.

## Hướng dẫn bổ sung

- **Định dạng**: WebP (best), PNG (transparency), JPG (photos).
- **Kích thước**:
  - Desktop: 3840x2160 (4K) hoặc 1920x1080 (HD).
  - Mobile portrait: 1080x1920.
- **Light + Dark variants**: cung cấp cả 2 phiên bản cho mỗi background để theme switch.

## Cần bổ sung (sau khi sếp cung cấp)

- `gradient-mesh.webp` / `gradient-mesh-dark.webp` — gradient mesh cho home/landing screen
- `noise-texture.webp` — texture nhiễu overlay cho glass surfaces
- `blueprint.svg` — pattern bản vẽ kỹ thuật (cho design taste `industrial` / `technical`)
- `mesh-01.webp` ... `mesh-12.webp` — các mesh patterns
- `particles.webp` — particle overlay cho animated backgrounds
- `splash-light.webp`, `splash-dark.webp` — splash screen
- `auth-bg.webp`, `auth-bg-dark.webp` — background cho auth/onboarding
