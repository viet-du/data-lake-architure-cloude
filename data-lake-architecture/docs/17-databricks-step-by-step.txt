╔══════════════════════════════════════════════════════════════╗
║  BƯỚC 7: CHẠY CODE DELTA LAKE ĐẦU TIÊN                     ║
╚══════════════════════════════════════════════════════════════╝

⌨️ Trong cell đầu tiên của notebook, paste code này:

   # Cell 1: Test Spark
   print("Hello from Databricks! 🎉")
   print(f"Spark version: {spark.version}")

   → Click nút ▶️ (play) ở góc trên của cell
   → Đợi vài giây
   → Output: "Hello from Databricks!"

⌨️ Tạo cell mới (click + Code):

   # Cell 2: Tạo sample data
   data = [
       (1, "iPhone 15", "smartphone", 29990000),
       (2, "MacBook Pro", "laptop", 49990000),
       (3, "AirPods Pro", "headphone", 5990000),
       (4, "iPad Air", "tablet", 15990000),
       (5, "Apple Watch", "smartwatch", 9990000),
   ]
   
   df = spark.createDataFrame(data, ["id", "name", "category", "price"])
   display(df)

   → Click ▶️
   → Output: Bảng hiển thị 5 rows

⌨️ Cell 3: Ghi Delta Lake:

   # Cell 3: Ghi vào Delta Lake
   df.write.format("delta").mode("overwrite").save("dbfs:/data/delta/products/")
   
   print("✅ Saved to Delta Lake!")

   → Click ▶️
   → Output: "✅ Saved to Delta Lake!"

⌨️ Cell 4: Đọc lại từ Delta Lake:

   # Cell 4: Đọc lại từ Delta Lake
   df_delta = spark.read.format("delta").load("dbfs:/data/delta/products/")
   display(df_delta)

   → Click ▶️
   → Output: Bảng hiển thị data đã lưu

   → Settings → User Settings → Generate new token
